# Route -> client guard -> server enforcement matrix (D-01)

Generated from `raw/authz-route-matrix.json` (`raw/authz-routes.py`), then annotated by hand. "Page guard" is a `if (!hasPermission(P.X)) return <Navigate/>` or a page-wrapping `<PermissionGate>`; "Other client gates" are button/section-level. Server column lists, for each client write, the latest RLS predicate (`woreda` = `woreda_id = get_user_woreda_id()`; perms = `user_has_any_perm(...)` keys). Every policy also admits `is_super_admin()` except service_request writes. Layout routes (`woreda.tsx`, `woreda.credentials.tsx`, `woreda.civil.tsx`, `woreda.revenue.tsx`, `woreda.services.tsx`) apply `ModuleGate` to all children; `woreda.tsx` checks only that a role exists (no `status` check, unlike `admin.tsx:25-32`).
